The wedding invitation that takes over your phone

2:21 min
Written by Caroline D'Cruz, journalist and editor with 16+ years of experience, founder of The Elders Club · Last updated 29 September 2026

Over 150 people have already lost control of their phones this wedding season — all from opening a single file. This guide walks through exactly what a fake wedding invitation file looks like on WhatsApp, why it's more dangerous than most scams, and what to ask for instead of a downloadable file.

The steps, written out

1

Know what this scam looks like

Scammers send you a wedding invitation file on WhatsApp, often from a number you don't recognise. It's designed to look exactly like a real e-invite.

On screen: A wedding invitation file in WhatsApp

2

Check the file before you open it

Look closely at the file name. A real PDF never ends in .apk — if it does, it's an app trying to install itself, not a document, no matter how official the wedding card looks.

On screen: Filename ending in .apk

3

Know why this one is dangerous

The moment it's installed, it can take control of your phone, uninstall WhatsApp, freeze your phone completely, and forward the same file to your known contacts — from your own account.

On screen: What happens after installing

4

Ask for this instead

If you're unsure about a wedding invite file, ask the sender for a plain photo instead, or a plain text message with the wedding details — never a downloadable file.

On screen: Asking for a photo instead

5

Always check before you click

Get into the habit of checking any file or link before opening it, especially ones you weren't expecting — this one habit stops almost every version of this scam.

On screen: Checking a file before opening

6

If you've already opened it, don't panic

Don't enter your OTP, password, or UPI PIN on anything the file opens. Closing the app and acting quickly matters more than panicking.

On screen: Not entering OTP or PIN

7

Report it straight away

Call the National Cyber Fraud Helpline on 1930 to report it. Acting quickly gives you the best chance of protecting your phone and your money.

On screen: Calling the 1930 helpline

If something goes wrong

How can I tell a wedding invitation file is fake?

Check the file name — if it ends in .apk instead of .pdf, it's an app pretending to be a document, no matter how genuine the wedding card design looks.

What should I ask for instead of a downloadable wedding invite?

A plain photo of the invitation, or a plain text message with the wedding details — both are safe, and neither can install anything on your phone.

Can this scam spread to my contacts on its own?

Yes — once installed, it can use your WhatsApp to forward the same file to your known contacts, so a message “from” someone you trust doesn't mean they actually sent it.

What should I do if I've already opened a suspicious file?

Don't enter any OTP, password, or UPI PIN. Call the National Cyber Fraud Helpline on 1930 straight away to report it.

What you'll walk away knowing

By the end of this guide, made free and step-by-step by The Elders Club, you'll be able to:

  • Spot a fake wedding invitation file before you open it
  • Know why this scam is especially dangerous
  • Know what to ask for instead of a downloadable file
  • Know exactly what to do if you've already opened it

The file name is the giveaway every time — a real wedding card is never a file ending in .apk. Ask for a photo or a plain text message instead, and this scam has nowhere to go.
